# Age Calculator

A small Flask web application that calculates age in years, months, and days.

## Run on Windows

In PowerShell, from this folder:

    py -3.11 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r .\requirement.txt
    .\.venv\Scripts\python.exe app.py

Open http://127.0.0.1:5000/ in your browser.

The Azure DevOps pipeline is in azure-pipelines.yml.
